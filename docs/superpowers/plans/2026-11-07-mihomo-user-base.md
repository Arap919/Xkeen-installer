# Пользовательский базовый Mihomo в сборке

Заменить прежний минимальный встроенный шаблон полным пользовательским конфигом: порты, DNS, геобазы, провайдеры, группы и правила. Исходный YAML хранится встроенным без URL подписок. Существующие установки не перезаписываются.

При генерации из единственного поля подписки используется PaperVPN; незаполненный BlancVPN исключается из рабочего экземпляра и ссылок на него. Для двух разных подписок доступен существующий импорт полного YAML. API и benchmark рабочего экземпляра остаются на loopback; генерируется API secret. Для watchdog используются Proxy/BENCHMARK и одинаковый набор включённых провайдеров. Эти адаптации объясняются в интерфейсе. Исходный встроенный файл сохраняет оба провайдера и пользовательские значения.
