## Подтверждённый пакетный сценарий KeeneticOS 5.1.8

KN-2610 сообщает hw_id KN-2610, arch mips; интерактивный show version и exit завершаются кодом 0. Пакетный LF-ввод show version/exit через ssh -tt воспроизводит зависание: команды отражаются до баннера, затем появляется (config)> без выполнения show version.

- [x] Регрессионная SSH-фикстура с отбрасыванием ввода до приглашения, CRLF, fragmented prompt и пагинацией.
- [x] RunCLI ждёт стартовое приглашение, держит stdin открытым, отправляет команду после готовности, ждёт ответ и закрывает CLI через exit. Подтверждения неизвестных запросов не отправляются; mutation без явного успеха остаётся uncertain.
- [ ] Go/race/frontend проверки, ревью и macOS ARM64/ZIP; проверка на устройстве остаётся за повторным запуском пользователя.

Исправленный prompt-driven RunCLI: тесты TestCLI прошли 20 повторов с race detector (`go test -race ./internal/router -run TestCLI -count=20`). macOS ARM64 сборка прошла; оба встроенных конфига сохранены. Повторный полный go test ./... в этой фазе не выполнялся: разрешение на команду отклонено. Независимое статическое ревью не нашло блокеров. Физический роутер при разработке не изменялся; требуется повтор шага пользователем.
