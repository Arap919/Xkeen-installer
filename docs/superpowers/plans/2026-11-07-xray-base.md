# Базовый Xray-конфиг из пользовательского Mihomo

Цель: заменить встроенный минимальный Xray-шаблон маршрутами предоставленного Mihomo, сохранив настройки существующих установок.

Решение: JSON-шаблон в существующем go:embed; значения по умолчанию групп преобразуются в статические маршруты direct/proxy/block. Прокси остаётся blocked-until-configured без вымышленных реквизитов; запуск незаполненного шаблона запрещён существующим механизмом. Прозрачный порт 50080 сохраняется для XKeen. Геокатегории требуют совместимых geoip.dat/geosite.dat; источники и отличия DNS, подписок и групп описываются отдельно. Сам Mihomo-шаблон не меняется.

- [x] Заменить JSON-шаблон, уточнить сообщение настройки и описать перенос/зависимости.
- [x] Выполнить Go-проверки, нативную проверку JSON при доступности ядра и сборку macOS ARM64/ZIP.

Проверено: ожидаемый RED нового шаблона и прежней базы; затем go test ./..., go vet ./..., нативный Xray 26.10.31 с источниками геобаз из пользовательского конфига: Configuration OK. Сборка Wails darwin/arm64 прошла; JSON проверен как встроенный массив байтов в исполняемом файле. Независимое статическое ревью: блокирующих замечаний нет. На роутере и других ОС не запускалось.
