# XKeen Installer

Графический мастер установки XKeen, Mihomo/Xray, router-watchdog и XKeen UI PWA на подготовленный Keenetic.

Мастер требует заранее подготовленного Entware, SSH с POSIX shell и доступа к `/opt`. Настройки KeeneticOS, форматирование накопителя, выбор OPKG, DNS, политики клиентов и перезагрузка выполняются вручную. SMB-передача до Entware пока не подтверждена.

Последовательность работы: подготовка → подключение → проверка → ядра → компоненты → конфигурация → просмотр и подтверждение плана → установка → проверка результата. Конфликты конфигурации требуют ручного согласования. До записи создаётся проверяемая закрытая резервная копия. Отмена не откатывает выполненные изменения; повтор требует новой проверки.

Пароли и подписки не сохраняются в browser storage или отчётах. Первый ключ SSH подтверждается отдельно и хранится в памяти до закрытия приложения; неожиданная замена блокируется. Новый CA и его ключ сохраняются только в закрытом локальном хранилище приложения. Установка доверия CA требует отдельного подтверждения. На других устройствах доверие настраивается вручную.

Для разработки нужны Go 1.26+, Node.js 22.12+ из ветки 22 либо 24+, npm и системные зависимости Wails v2. macOS требует Xcode Command Line Tools, Windows — WebView2, Linux — поддерживаемые GTK/WebKitGTK development packages. Подробности: [установка Wails](https://v2.wails.io/docs/gettingstarted/installation/).

```sh
cd frontend
npm ci
npm test
npm run build
cd ..
go test -race ./...
go run github.com/wailsapp/wails/v2/cmd/wails@v2.17.1 build
```

На macOS собранное приложение находится в `build/bin/xkeen-installer.app`. Для разработки: `go run github.com/wailsapp/wails/v2/cmd/wails@v2.17.1 dev`.

Первая целевая матрица: Windows amd64, macOS amd64/arm64, Linux amd64. Успех локальной сборки не подтверждает остальные платформы. Проверки через fake backend не заменяют реальную установку на роутер; она требует отдельного разрешения.
